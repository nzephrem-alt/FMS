# ISTA FORTIS Financial Management System

React + TypeScript + Vite starter. The existing dashboard has been separated into reusable components and page modules.

## Run locally
1. Run `npm install` in this folder.
2. Run `npm run dev`.
3. Open the local URL shown by Vite (usually http://localhost:5173).
4. Check the production build with `npm run build`.

`src/components` contains shared UI components. `src/pages` contains page modules. `src/index.css` is the single global stylesheet. Dashboard figures are illustrative preview data only.
